openjp2 playground

Decode and encode JPEG 2000 (.jp2 / .j2k) entirely in the browser with the pure-Rust OpenJPEG port — no server round-trips.

Decode

Drop a .jp2 / .j2k codestream here, or click to browse. Multi-tile codestreams decode in parallel.

drop a JP2/J2K file

Encode

Drop any image the browser can read (PNG, JPEG, WebP, ...) to encode it to JPEG 2000.

drop an image

Explorer

Byte-level view of the loaded codestream: marker segments are highlighted — click one for its meaning and a link into the JPEG 2000 spec. The truncation slider cuts the codestream and re-decodes it live (lenient mode tolerates truncated files).

decode a file first
Powered by openjp2, a pure-Rust port of OpenJPEG. Encoded/decoded pixels never leave your browser.
